# Система учёта посещаемости студентов

Автор: Царёв П. В.  
Группа: 26-ИВТ-4-1.

## Описание проекта

Учебное консольное приложение на Python для учёта посещаемости
занятий студентами.

Система хранит сведения о студентах, учебных группах, преподавателях,
занятиях и отметках посещаемости. Для пользователей предусмотрены
авторизация и разделение возможностей по ролям.

Данные хранятся в SQLite. Экспорт списка студентов и связанных
с ними групп выполняется в JSON, CSV, XML и YAML.

Проект разрабатывается последовательно в рамках лабораторных работ.
История изменений хранится в Git, репозиторий размещён на GitHub.

## Предметная область

Основные сущности системы:

- учебная группа;
- студент;
- преподаватель;
- занятие;
- отметка посещаемости;
- учётная запись пользователя.

Студент относится к учебной группе. Занятие проводится для группы
определённым преподавателем. Отметка посещаемости связывает
студента и занятие.

Поддерживаются следующие статусы посещаемости:

| Значение в базе | Значение для пользователя |
|---|---|
| present | Присутствовал |
| absent | Отсутствовал |
| excused | Отсутствовал по уважительной причине |

Отсутствие записи о посещаемости означает, что отметка ещё не внесена.

## Пользователи системы

| Роль | Реализованные действия |
|---|---|
| Администратор | Просмотр студентов, просмотр и добавление групп |
| Преподаватель | Просмотр своих занятий, отметка посещаемости |

Учётные записи хранятся в таблице users.
Пароли сохраняются в виде хешей.

## Установка и запуск

Все команды выполняются из корневой папки проекта.

### Установка зависимости

Для экспорта YAML требуется библиотека PyYAML:

bash python -m pip install PyYAML
Остальные используемые модули входят в стандартную библиотеку Python.

В PyCharm библиотеку необходимо установить в тот интерпретатор,
который выбран для проекта.

### Запуск основной программы

bash python src/main.py
При запуске программа подготавливает базу данных,
предлагает авторизацию и открывает меню соответствующей роли.

Для запуска в PyCharm открыть src/main.py
и выбрать Run 'main'.

### Подготовка базы отдельно

bash python src/init_sqlite.py
Скрипт создаёт таблицы и добавляет недостающие учебные записи.

Повторный запуск не очищает базу и не заменяет существующие записи
с теми же идентификаторами.

### Проверка базы

bash python src/check_sqlite.py
Скрипт выводит сведения о данных и проверяет внешние ключи.

### Запуск экспорта

bash python src/export_lab5.py
Перед первым экспортом база должна быть подготовлена через
src/main.py или src/init_sqlite.py.

Вводить данные при запуске экспорта не требуется.

Программа автоматически создаёт папку out
и сохраняет в неё четыре файла:

- data.json;
- data.csv;
- data.xml;
- data.yaml.

В консоль выводятся пути к созданным файлам.
При повторном экспорте файлы перезаписываются.

## База данных

### Таблицы

| Таблица | Назначение | Первичный ключ | Внешние ключи |
|---|---|---|---|
| groups | Учебные группы | group_id | — |
| teachers | Преподаватели | teacher_id | — |
| students | Студенты | student_id | group_id → groups.group_id |
| lessons | Занятия | lesson_id | group_id → groups.group_id, teacher_id → teachers.teacher_id |
| attendance | Отметки посещаемости | attendance_id | lesson_id → lessons.lesson_id, student_id → students.student_id |
| users | Учётные записи | user_id | student_id → students.student_id, teacher_id → teachers.teacher_id |

### Связи и ограничения

- Одна группа может содержать нескольких студентов.
- Для одной группы может проводиться несколько занятий.
- Один преподаватель может проводить несколько занятий.
- Связь студентов и занятий реализована через таблицу attendance.
- UNIQUE (lesson_id, student_id) запрещает повторную отметку
  одного студента на одном занятии.
- CHECK ограничивает допустимые роли и статусы посещаемости.
- UNIQUE для ссылок в users запрещает несколько учётных записей
  для одного студента или преподавателя.

У администратора обе ссылки — student_id и teacher_id — пустые.
У студента заполнен только student_id,
у преподавателя — только teacher_id.

При открытии соединения включается проверка внешних ключей.
## Лабораторная работа №5 — форматы данных

### Задача

Получить записи таблицы, содержащей связь с другой таблицей,
и сохранить данные в JSON, CSV, XML и YAML.

Для экспорта выбрана таблица students,
связанная с таблицей groups по полю group_id.

### Получение данных

В src/repositories/export_repository.py выполняется запрос:

sql SELECT
    s.student_id,
    s.full_name,
    g.group_id,
    g.name
FROM students AS s
LEFT JOIN "groups" AS g
    ON s.group_id = g.group_id
ORDER BY s.student_id;
Запрос получает всех студентов и сведения об их группах.

### Подготовка данных

Функция get_students_data() преобразует строки SQL-запроса
в список словарей Python.

Группа представлена вложенным словарём:

python {
    "student_id": 1,
    "full_name": "Иванов Павел Сергеевич",
    "group": {
        "group_id": 1,
        "name": "26-ИВТ-4-1"
    }
}
### Форматы экспорта

| Формат | Файл | Представление связанных данных |
|---|---|---|
| JSON | out/data.json | Вложенный объект group |
| CSV | out/data.csv | Колонки group.group_id и group.name |
| XML | out/data.xml | Вложенный элемент <group> |
| YAML | out/data.yaml | Вложенные поля под ключом group |

Для CSV функция flatten_dict() раскрывает вложенные словари.
Названия колонок формируются из ключей данных.

Для XML функция add_xml_elements() рекурсивно создаёт элементы
для полей и вложенных словарей.

JSON и YAML записываются средствами библиотек,
которые самостоятельно обрабатывают вложенные словари.

Функции экспорта получают подготовленные данные и не выполняют
SQL-запросы. При выборе другой таблицы меняются запрос
и подготовка словарей; существующие функции записи можно
использовать для данных аналогичной структуры.
